**Goal:** Ship plugin 0.16.0 (whole-word private terms, legacy rules on demand, `\uXXXX` in the hook, a public plugin wiki) and prepare the app for it, with the field-test project's name and the Mac path gone from both public repos.

**Tech Stack:** POSIX sh + awk, Python 3.10 (validator, generators), Markdown workflows; app: Rust (cargo, pinned crates), TypeScript (node --test).

**Spec:** `docs/superpowers/specs/2026-11-18-release-0.16.0-design.md`

## Review Focus

1. `.private-terms` holding only `=` lines (no substring lines) → no empty pattern file reaches `grep -f` (an empty line matches everything). Test: "only whole-word terms" in Task 1.
2. A `=` line written with CRLF or trailing spaces (`=Acme  \r`) → still the whole word `Acme`. Test: "whole-word CRLF" in Task 1; Rust test `whole_word_trims` in Task 7.
3. A bare `=` line → ignored, never "match everything". Tests: "bare equals ignored" (Task 1), `bare_equals_ignored` (Task 7).
4. A malformed escape (`\u12`, `\uZZZZ`) in a hook payload → kept literally, the hook still exits 0. Test: "malformed unicode escape" in Task 3.
5. A v1 wiki (no `## Core map`) after the legacy split → the common prompt still sends the agent to the legacy file. Checked by the trigger-line grep in Task 4 Step 3.
