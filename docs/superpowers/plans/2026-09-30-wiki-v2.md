# Codebase Wiki LLM v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Codebase Wiki LLM 0.9.0: a smaller core wiki (context, log, decisions), a one-message init survey with adopt mode, evidence/budget/confidentiality lint checks, and shared hooks for Claude Code, Codex and Antigravity — all generated from one source.

**Architecture:** All prompt text lives in `canonical/codebase/`, all scripts in `canonical/codebase/scripts/`. `scripts/generate-codebase-packages.py` turns them into three host packages under `plugins/` plus the generic `skills/` tree; `scripts/generate-host-packages.py` also writes `.claude-plugin/marketplace.json`. Scripts are POSIX `sh`, no `jq`, no Python at runtime. Configuration read by scripts is one-value-per-line files (`.wikidir`, `.private-terms`, `VERSION`); configuration read by agents is Markdown tables in the target repo's `SCHEMA.md`.

**Tech Stack:** POSIX sh, git, Python 3 (generators and repo tests only), Markdown.

**Spec:** `docs/superpowers/specs/2026-09-30-wiki-v2-design.md`

## Global Constraints

- Scripts: POSIX `sh`, always `exit 0` from hooks unless the hook's contract says otherwise; no `jq`; never echo an invalid `.wikidir` value or a private term.
- `.wikidir` rules and resolver messages are unchanged for v1 users (existing tests in `scripts/test-resolve-wiki-root.sh` must keep passing untouched).
- No host-specific wording in `canonical/`. Host differences only in generators.
- Canonical text uses `<wiki-root>/`, never a hard-coded `wiki/` (enforced by `scripts/check-generated.sh`).
- Generated files under `plugins/` and `skills/` are never edited by hand.
- Versions: codebase `0.9.0`, secondbrain `0.2.1` (unchanged), read from `canonical/<plugin>/VERSION`.
- Core map roles (exact names): `index`, `log`, `log-archive`, `tracker`, `decisions`, `risks`, `context`, `handoff`, `troubleshooting`, `glossary`.
- Default budgets: page 20 KB; per-session read set 40 KB; `log.md` 30 KB.
- Default conventions: ID prefix `T`; 🟢 done and verified · 🟡 in progress · ⚪ to do · 🔴 blocked (work stopped).
- Stale handoff threshold in the resolver: 5 commits.
- Commit messages in English, imperative, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A repository with `git init` but no commits: resolver, reminder and private-terms check must print nothing unexpected and exit 0 (tests in Tasks 2, 3, 4).
- A `SCHEMA.md` Core map value that is absolute or contains `..`: scripts fall back to the default path, never read outside the wiki (test in Task 2).
- `.private-terms` written on Windows (CRLF), with blank lines and `#` comments: comments and blanks ignored, CR stripped, matching case-insensitive (test in Task 3).
- The private term appearing in the committed `SCHEMA.md` itself: must be flagged (only `.private-terms` is excluded) (test in Task 3).
- Renamed files and paths with spaces in `git status`: reminder classifies them correctly as inside/outside the wiki (test in Task 4).

- [ ] **Step 3: Rewrite the resolver** — `canonical/codebase/scripts/resolve-wiki-root.sh`

```sh
#!/bin/sh
# Print this repository's Codebase Wiki root for the agent session context.
# Claude Code and Codex run it as a plugin SessionStart hook; the resolution
# rule is canonical/codebase/partials/resolve-wiki-root.md.
# Copied into the host packages by scripts/generate-codebase-packages.py.
# --print-root: print only the bare root value (for other scripts), or nothing.
# Always exits 0 and prints nothing when the repository has no wiki.
# The pointer is repository content: an invalid value is never echoed.

STALE_COMMITS=5
mode=context
[ "${1:-}" = "--print-root" ] && mode=print

root=$(git rev-parse --show-toplevel 2>/dev/null) || root=$(pwd)
pointer="$root/.wikidir"
wiki=
msg=

if [ -f "$pointer" ]; then
  # Drop NUL bytes, UTF-8/UTF-16 BOM bytes and CR so files written by
  # PowerShell still read as plain ASCII; valid names are ASCII only.
  value=$(tr -d '\000\015\357\273\277\376\377' < "$pointer" | sed -n '/[^[:space:]]/{p;q;}' | sed 's/^[[:space:]]*//; s/[[:space:]]*$//')
  lower=$(printf '%s\n' "$value" | tr '[:upper:]' '[:lower:]')
  case "$lower" in
    .git|.github|.claude|.codex|.agents|.agent|.gemini|.opencode|.obsidian|.vscode|node_modules|.wikidir)
      valid=no ;;
    *)
      if printf '%s\n' "$value" | grep -Eq '^\.?[A-Za-z0-9]([A-Za-z0-9._-]*[A-Za-z0-9_-])?$'; then
        valid=yes
      else
        valid=no
      fi ;;
  esac
  if [ "$valid" = no ]; then
    msg="Codebase Wiki LLM: .wikidir does not contain a valid wiki folder name."
  elif [ -d "$root/$value" ]; then
    wiki=$value
  else
    msg="Codebase Wiki LLM: .wikidir points to missing directory $value."
  fi
elif [ -f "$root/wiki/SCHEMA.md" ]; then
  wiki=wiki
fi

if [ "$mode" = print ]; then
  [ -n "$wiki" ] && printf '%s\n' "$wiki"
  exit 0
fi

[ -n "$msg" ] && echo "$msg"
[ -n "$wiki" ] || exit 0
echo "Codebase Wiki LLM: wiki_root: $wiki"

# Core map path for a role, relative to the wiki root; default when absent or unsafe.
core_path() {
  p=$(sed -n "s/^|[[:space:]]*$1[[:space:]]*|[[:space:]]*\`\{0,1\}\([^\`|]*\)\`\{0,1\}[[:space:]]*|.*/\1/p" "$root/$wiki/SCHEMA.md" 2>/dev/null | head -n 1 | sed 's/[[:space:]]*$//')
  case "$p" in ''|/*|*..*) p=$2 ;; esac
  printf '%s\n' "$p"
}

handoff="$wiki/$(core_path handoff agent/handoff.md)"
if [ -f "$root/$handoff" ]; then
  last=$(git -C "$root" log -1 --format=%H -- "$handoff" 2>/dev/null)
  if [ -n "$last" ]; then
    n=$(git -C "$root" rev-list --count "$last..HEAD" 2>/dev/null) || n=0
    if [ "$n" -ge "$STALE_COMMITS" ]; then
      echo "Codebase Wiki LLM: handoff is $n commits old ($handoff); read it and refresh it before relying on it."
    fi
  fi
fi
exit 0
```

# expect <case> <dir> <expected exit> <args...>; stderr saved in $TMP_DIR/err
expect() {
  local name="$1" dir="$2" want="$3" got=0
  shift 3
  (cd "$dir" && sh "$CHECK" "$@") 2>"$TMP_DIR/err" || got=$?
  [ "$got" = "$want" ] || { echo "FAIL $name: exit $got, expected $want" >&2; cat "$TMP_DIR/err" >&2; failures=$((failures + 1)); }
}

new_repo() {
  local dir="$TMP_DIR/$1"
  mkdir -p "$dir/wiki"
  git -C "$dir" init -q
  printf '%s\n' "$dir"
}

r="$(new_repo no-terms)"; echo "Acme rocket" > "$r/a.txt"; git -C "$r" add a.txt
expect "no terms file passes" "$r" 0

r="$(new_repo staged-hit)"; printf 'Acme\n' > "$r/wiki/.private-terms"
printf 'line one\nWe work with acme corp\n' > "$r/a.txt"; git -C "$r" add a.txt
expect "staged hit blocks" "$r" 1
grep -q "a.txt:2" "$TMP_DIR/err" || { echo "FAIL staged hit: file:line missing" >&2; failures=$((failures + 1)); }
if grep -qi "acme" "$TMP_DIR/err"; then echo "FAIL staged hit: term echoed" >&2; failures=$((failures + 1)); fi

r="$(new_repo unstaged)"; printf 'Acme\n' > "$r/wiki/.private-terms"

expect "unstaged change passes --staged" "$r" 0
expect "unstaged change fails --all" "$r" 1 --all

#!/bin/sh
# Block content that contains a term listed in <wiki-root>/.private-terms.
#   (no argument) / --staged  search the git index (git pre-commit hook)
#   --all                     search tracked files in the working tree (/wiki-lint)
# /wiki-init copies this file to .git/hooks/pre-commit, so it is standalone.
# Exit 0: clean, no repo, or no terms. Exit 1: hits (file:line on stderr,
# never the term itself). Exit 2: usage.

case "${1:-}" in
  ""|--staged) cached=--cached ;;
  --all) cached= ;;
  *) echo "usage: check-private-terms.sh [--staged|--all]" >&2; exit 2 ;;
esac

root=$(git rev-parse --show-toplevel 2>/dev/null) || exit 0
wiki=wiki
if [ -f "$root/.wikidir" ]; then
  wiki=$(tr -d '\000\015\357\273\277\376\377' < "$root/.wikidir" | sed -n '/[^[:space:]]/{p;q;}' | sed 's/^[[:space:]]*//; s/[[:space:]]*$//')
fi
case "$wiki" in ''|.|..|*/*) exit 0 ;; esac

terms="$root/$wiki/.private-terms"
[ -f "$terms" ] || exit 0
patterns=$(mktemp) || exit 2
trap 'rm -f "$patterns"' EXIT
tr -d '\015' < "$terms" | sed 's/^[[:space:]]*//; s/[[:space:]]*$//' | grep -v -e '^#' -e '^$' > "$patterns"
[ -s "$patterns" ] || exit 0

# shellcheck disable=SC2086 # $cached is empty or one flag
hits=$(cd "$root" && git grep $cached -I -i -F -n -f "$patterns" -- . ":(exclude)$wiki/.private-terms" | cut -d: -f1-2)
if [ -n "$hits" ]; then
  echo "Codebase Wiki LLM: private terms found (list in $wiki/.private-terms):" >&2
  printf '%s\n' "$hits" >&2
  echo "Replace them with the generic wording recorded in SCHEMA.md." >&2
  exit 1
fi
exit 0
```

#!/bin/sh
# Stop hook: when files outside the wiki changed and the wiki did not, ask the
# agent once to run the wiki sync workflow.
#   remind-wiki-sync.sh --host claude        Claude Code and Codex
#   remind-wiki-sync.sh --host antigravity   Antigravity (cwd is the plugin folder)
# Reads the hook payload on stdin. Prints nothing and exits 0 when there is
# nothing to say. Only uncommitted changes are seen; commits made during the
# session are covered by the stale-handoff notice at session start.

host=claude
[ "${1:-}" = "--host" ] && host=${2:-claude}
payload=$(cat | tr -d '\n')

case "$payload" in *'"stop_hook_active":true'*|*'"stop_hook_active": true'*) exit 0 ;; esac

if [ "$host" = antigravity ]; then
  dir=$(printf '%s' "$payload" | sed -n 's/.*"workspacePaths"[[:space:]]*:[[:space:]]*\[[[:space:]]*"\([^"]*\)".*/\1/p')
  [ -n "$dir" ] || exit 0
else
  dir=$(printf '%s' "$payload" | sed -n 's/.*"cwd"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p')
  [ -n "$dir" ] || dir=$(pwd)
fi
[ -d "$dir" ] || exit 0

root=$(git -C "$dir" rev-parse --show-toplevel 2>/dev/null) || exit 0
script_dir=$(CDPATH='' cd -- "$(dirname -- "$0")" && pwd)
wiki=$(cd "$root" && sh "$script_dir/resolve-wiki-root.sh" --print-root)
[ -n "$wiki" ] || exit 0

status=$(git -C "$root" status --porcelain --untracked-files=all 2>/dev/null)
[ -n "$status" ] || exit 0

wiki_re=$(printf '%s' "$wiki" | sed 's/\./\\./g')
paths=$(printf '%s\n' "$status" | cut -c4- | sed 's/.* -> //; s/^"//; s/"$//')
inside=$(printf '%s\n' "$paths" | grep -c -e "^$wiki_re/" -e '^\.wikidir$')
outside=$(printf '%s\n' "$paths" | grep -v -c -e "^$wiki_re/" -e '^\.wikidir$')
[ "$outside" -gt 0 ] && [ "$inside" -eq 0 ] || exit 0

marker="$(git -C "$root" rev-parse --absolute-git-dir)/codebase-wiki-sync-reminded"
state=$(printf '%s\n' "$status" | cksum)
[ -f "$marker" ] && [ "$(cat "$marker")" = "$state" ] && exit 0
printf '%s\n' "$state" > "$marker" 2>/dev/null

reason='Code changed but the wiki did not. Run the wiki sync workflow (/wiki-sync): log entry, tracker, handoff. If the change needs no wiki update, say why in one line.'
if [ "$host" = antigravity ]; then
  printf '{"decision":"continue","reason":"%s"}\n' "$reason"
else
  printf '{"decision":"block","reason":"%s"}\n' "$reason"
fi
exit 0
```

CORE_MAP_ROW = re.compile(r"^\|\s*([a-z-]+)\s*\|\s*`?([^`|]+?)`?\s*\|", re.MULTILINE)


def core_path(wiki_dir: Path, role: str, default: str) -> Path:
    schema = wiki_dir / "SCHEMA.md"
    if schema.is_file():

    return wiki_dir / default
